# ❤️ HeartCare AI - Heart Disease Risk Assessment System

HeartCare AI is a Streamlit-based web application that leverages a Machine Learning (K-Nearest Neighbors) pipeline to predict cardiovascular disease risk based on patient clinical measurements and profiles.

## 🚀 Live Demo
🔗 **[https://heartcare-ai-pred.streamlit.app/]**

---

## ✨ Features
- **Modern UI/UX**: Designed with professional healthcare-themed custom CSS gradients and responsive layouts.
- **Smart Data Encoding**: Uses `pandas` to dynamic-align inputs matching the ML training schema.
- **Flexible UI Controls**: Incorporates Streamlit's experimental `st.pills` component with standard fallback mechanisms.
- **Comprehensive Patient Metrics**: Collects demographic, laboratory, and automated ECG analysis values.

---

## 🛠️ Tech Stack & Architecture

- **Frontend/Framework**: [Streamlit](https://streamlit.io)
- **Data Manipulation**: [Pandas](https://pydata.org)
- **Machine Learning**: Scikit-Learn (K-Nearest Neighbors Classifier)
- **Model Serialization**: Joblib

### Project Directory Structure
```text
├── .streamlit/
│   └── config.toml         # Optional theme configurations
├── app.py                  # Main Streamlit application source code
├── KNN_heart.pkl           # Trained K-Nearest Neighbors model object
├── scaler.pkl              # Fitted StandardScaler object 
├── columns.pkl             # Serialization list of expected feature columns
├── requirements.txt        # Production dependencies
└── README.md               # Documentation
```

## 📊 Features Evaluated by the Model

| Category | Feature Name | Description | Input Type |
| :--- | :--- | :--- | :--- |
| **Profile** | `Age` | Patient age (18 - 100) | Slider |
| | `Sex` | Gender (Male / Female) | Interactive Pills / Selectbox |
| | `ChestPainType` | ATA, NAP, TA, ASY | Dropdown List |
| **Clinical** | `RestingBP` | Resting blood pressure in mm Hg | Numerical Input |
| | `Cholesterol` | Serum cholesterol level in mg/dL | Numerical Input |
| | `FastingBS` | Fasting Blood Sugar > 120 mg/dL (1 = true; 0 = false) | Binary Dropdown |
| **ECG Metrics**| `MaxHR` | Maximum heart rate achieved (50 - 220) | Slider |
| | `Oldpeak` | ST depression induced by exercise relative to rest | Float Slider |
| | `RestingECG` | Normal, ST, LHV wave analysis | Dropdown List |
| | `ExerciseAngina`| Exercise-induced angina (Yes / No) | Interactive Pills |
| | `ST_Slope` | The slope of the peak exercise ST segment (Up/Flat/Down) | Dropdown List |

## ⚙️ Installation & Local Setup

Follow these simple steps to run HeartCare AI on your machine:

### 1. Clone the Repository
```bash
git clone https://github.com/Ayush-Jaiswal-code99/Predict_Heart_Disease.git
cd Predict_Heart_Disease
```

### 2. Set Up a Virtual Environment (Recommended)
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
Ensure your environment contains the required models (`KNN_heart.pkl`, `scaler.pkl`, `columns.pkl`), then install requirements:
```bash
pip install streamlit pandas joblib scikit-learn
```

### 4. Boot up the Streamlit Application
```bash
streamlit run app.py
```
